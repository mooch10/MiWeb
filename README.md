## 🌟 Highlights & Technical Features

* **Lightweight & High-Speed:** Zero bloated framework overhead; engineered with pure semantic HTML5, modern vanilla JavaScript, and Tailwind CSS utility classes.
* **3D Visual Effects:** Dynamic canvas-rendered interactive particles and geometry utilizing **Three.js**.
* **AI-Agent & LLM Discoverability:** Implements the emerging `llms.txt` standard for automated context parsing by AI coding assistants, agents, and LLM search crawlers.
* **Modern Dark/Cyberpunk Aesthetics:** Custom glassmorphism, responsive typography (Space Grotesk, Plus Jakarta Sans, JetBrains Mono, Syne), and micro-interactions.
* **Mobile-First & Accessible:** Fully responsive across all viewports with smooth-scroll navigation and accessible contrast levels.

## 🚀 Running Locally

No complex build pipeline required. Simply serve the directory with any static HTTP server:

```bash
# Clone the repository
git clone https://github.com/mooch10/MiWeb.git
cd MiWeb

# Using Python
python -m http.server 8080

# Or using Node (npx)
npx serve .
```
Navigate to `http://localhost:8080` in your browser.
